# Elements, Modes and Dignities

## Elements and modes (public domain, quotable)

Sepharial's 1920 manual (Ch. II) states the classification in one passage, and because the book is public domain it can be quoted: "ELEMENTS. Fire—Aries, Leo, Sagittarius. Earth—Taurus, Virgo, Capricornus. Air—Gemini, Libra, Aquarius. Water—Cancer, Scorpio, Pisces. CONSTITUTIONS. Movable—Aries, Cancer, Libra, Capricornus. Fixed—Taurus, Leo, Scorpio, Aquarius. Flexed—Gemini, Virgo, Sagittarius, Pisces."

Sepharial's "Movable" is the modern Cardinal, and his "Flexed" is the modern Mutable. Leo uses Cardinal / Fixed / Mutable. This library uses the modern names and notes Sepharial's once, here.

Group keywords (Leo, Ch. XVI): Fire = energy, force, life, passions, higher emotions. Earth = practical, business, solid, matter-of-fact. Air = intellectual, mental, artistic, professional. Water = receptive, personal feelings, sensitive, psychic. Cardinal = intellect, ambition, ideality. Fixed = will, power, purpose. Mutable = emotion, flexibility, restlessness.

## Dignities (terminology anchor)

The classical dignity vocabulary — domicile ("houses of the planets"), triplicity, exaltation, terms, faces — is anchored in public-domain Ptolemy: *Tetrabiblos*, Ashmand translation, Book I, Ch. XX (Houses of the Planets), XXI (Triplicities), XXII (Exaltations), XXIII–XXIV (Terms), XXVI (Faces, Chariots). The companion skill does not weight dignities in its readings; this entry exists so the terms, when met in older sources, have a verified home.

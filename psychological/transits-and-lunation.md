# Transits and the Lunation Cycle — Approach Notes

## Transits: the public-domain anchor

Modern transit delineation (Hand and others) is in copyright. The openly reusable interpretation source is Alan Leo, *The Progressed Horoscope* (1906 edition, L. N. Fowler; public domain — Leo died 1917). Its contents include a transits section (§XIII "Transits"), the transits of each planet through the twelve houses, and "The General Effect of Transits". Two cautions: surviving scans are OCR-noisy, and some archive.org copies are later printings (one dated 1930) — cite and draw only from the 1906 Fowler edition.

The companion skill's daily method, stated in its own terms:

- A transit is read as function × arena: the transiting planet's function (planets.md) arriving in a natal house (houses.md), and — more importantly for the daily card — the aspect it makes to a natal planet (aspects.md).
- Fast bodies (Sun, Moon, Mercury, Venus, Mars) give the day's texture; Jupiter and Saturn give the week's weather. Anything slower is background, not a daily headline.
- Tightest orb first. A daily reading uses a handful of contacts, not the full list.
- The rating is computed by a fixed rule in the skill's script (tight harmonious contacts raise it, tight hard contacts lower it, floored at one star), so the stars never depend on the writer's mood.

## The lunation cycle: eight phases (facts)

The phase names and their 45° boundaries are facts and can be stated freely. The eightfold division is Dane Rudhyar's (*The Lunation Cycle*, 1967 — still in copyright; linked, not copied, see SOURCES.md). Keywords below are this library's own one-word glosses from each phase's geometry, not quotations.

| Phase | Sun–Moon angle | Gloss |
|---|---|---|
| New Moon | 0–45° | beginning |
| Crescent | 45–90° | emergence |
| First Quarter | 90–135° | action |
| Gibbous | 135–180° | refinement |
| Full Moon | 180–225° | illumination |
| Disseminating | 225–270° | sharing |
| Last Quarter | 270–315° | reorientation |
| Balsamic | 315–360° | release |

Rudhyar's wider point (restated): the lunation is a template — any two planets form a cycle with the same phase structure, which is how the framework file treats transiting pairs.

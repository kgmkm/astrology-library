# The Twelve Houses

House topics distilled from Sepharial, Ch. III "The Celestial Houses" (1920, public domain). Leo's *Astrology for All* gives no house-topic list; it notes only the affinity of houses with signs in order (1st house ~ Aries, 2nd ~ Taurus, and so on) and defers detail to a later volume, so this table is Sepharial's, lightly modernised in wording by this library (marked where a topic name is dated).

| House | Topics |
|---|---|
| 1st | personal appearance, face, head; the self as presented |
| 2nd | finance, movable possessions, commerce |
| 3rd | short journeys, letters and communication, near relations, neighbours |
| 4th | real estate, residence, produce of the earth, mother, end of life |
| 5th | children, sex instincts, domestic relations, social pleasures |
| 6th | health, servants (today: daily work and services), personal comforts, clothes, food, hygiene |
| 7th | marriage, contracts, agreements, partners, exchange |
| 8th | death, loss, legacies, dowries (today: shared resources and inheritance) |
| 9th | long journeys, publications, religious beliefs, foreign lands, legal affairs |
| 10th | position, honour, fame, father, superiors |
| 11th | friends, social relations, societies, companies |
| 12th | ambushes, restraints, privations, confinement, limits on freedom (today: hidden matters, retreat, what is kept out of sight) |

How the companion skill uses this: a house is read as the *arena* where a planet's function shows up ("through what circumstances they will likely be encountered", in the psychological-astrology framing). House topics are kept plain on purpose for general readers.

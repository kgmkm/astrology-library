# Glossary and Terminology Traps

- **Uranian astrology / Hamburg School** — the same system under two names. "Uranian" comes from the 1939 English translation by Richard Svehla.
- **TNP / Trans-Neptunian Points** — the eight hypothetical points (see tnp8.md). Not to be confused with:
  - **Trans-Neptunian Objects (TNOs)** in astronomy — real Kuiper-belt bodies. Unrelated.
  - Japanese **トランスサタニアン (trans-Saturnian)** — in Japanese astrology writing this means the *real* outer planets Uranus, Neptune and Pluto. It never means the TNPs. Japanese materials for this project call the TNPs ドイツ式架空天体 ("German-style hypothetical bodies") with a small "Uranian" note.
- **Midpoint / half-sum** — the same technique. "Half-sum" (Halbsumme) is Ebertin's term; "midpoint" is the common English term.
- **Planetary picture** — a set of bodies and midpoints sharing one axis, written as an equation (see midpoints.md). Not a drawing.
- **Cosmobiology** — Ebertin's offshoot: Hamburg technique (midpoints, dial) *without* the hypothetical points. If a source uses midpoints but no TNPs, it is usually Cosmobiology lineage.
- **Personal points** — MC, ASC, Sun, Moon, Node, Aries Point: the anchors a reading starts from.
- **Vulcanus vs Vulcan** — Vulcanus is one of the eight TNPs. "Vulcan" in openephem is a *different* hypothetical body (an intra-Mercurial point from another tradition), and TransPluto is a ninth, later point. Do not mix them in readings.
- Name variants in Japanese sources: Cupido appears as キューピッド／クピド, Vulcanus as ヴァルカン／ヴルカヌス, Admetos as アドメトス／アドメトゥス. This project keeps TNP names in English everywhere, which sidesteps the variants.
